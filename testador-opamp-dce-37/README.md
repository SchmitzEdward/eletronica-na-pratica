# Testador de amplificadores operacionais — DCE nº 37

Material complementar do vídeo publicado no canal Edward Schmitz.

Este projeto reconstrói o testador de amplificadores operacionais publicado na revista Divirta-se com a Eletrônica nº 37, de abril de 1984.

Durante a montagem, foram encontrados:

- layout invertido na placa de circuito impresso;
- valores incorretos no esquema original;
- dificuldades na montagem do circuito integrado;
- diferenças entre a frequência calculada e a frequência medida.

## Arquivos disponíveis

- esquema eletrônico redesenhado;
- explicação do funcionamento;
- formas de onda;
- cálculo da frequência;
- erratas identificadas.
