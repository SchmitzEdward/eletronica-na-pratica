# Cigarra Eletrônica — Saber Eletrônica nº 128 (maio de 1983)

Circuito de Newton C. Braga publicado na seção "Sítio Eletrônico", que reunia
circuitos imitando bichos: passarinho, boi, cigarra, pintinho e galinha.

A cigarra usa dois osciladores trabalhando juntos:

- um oscilador com transistor unijunção (2N2646), que gera a intermitência;
- um oscilador complementar (BC548 + BC558), que gera o som agudo.
